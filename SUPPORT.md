# Support

## How to file issues and get help

This project uses GitHub issues to track bugs and feature requests. Please search the existing issues before filing new issues to avoid duplicates. For new issues, file your bug or feature request as a new issue.

Please keep in mind what this repository is and is not:

- **Questions about this sample** — how it works, how to adapt it, or a problem running it — belong in this repository's issues.
- **Questions about the External custom properties API itself** — its behaviour, limits, or errors — are better directed at [GitHub Support](https://support.github.com/), since this repository is an example client rather than the API. The [REST API reference for organization custom properties](https://docs.github.com/en/rest/orgs/custom-properties) documents the endpoints this sample calls.

`external-custom-properties-sample` is under active development and maintained by GitHub staff. We will do our best to respond to support, feature requests, and community questions in a timely manner.

## GitHub Support Policy

Support for this project is limited to the resources listed above.
